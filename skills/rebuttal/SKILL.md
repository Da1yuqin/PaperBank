# Rebuttal skill

读准原问题，首句回答，再给证据和位置。回复讨论论文与证据，不评价审稿人的能力或动机。

## 使用前

核对当轮字数、匿名、补实验、链接、修订稿和 AI 使用规定。确认材料使用权限与工具的数据处理方式；未获许可，不向外部服务上传未公开稿件、review、个人数据或密钥。只在允许范围内使用 AI，按要求披露，由作者核实并定稿。

不编造结果、引用、审稿评价或已完成的修改，不隐藏影响判断的条件、负结果和错误。不提供规避 AI 规则或检测的做法。教学例子不能当作真实审稿记录或实测证据。

## 1. 拆问题

读取论文、完整 review、当前回复和已有结果。Summary 核对理解，Strengths 记录已认可点，Weaknesses 与 Questions 提取关切；建议与评分理由中有具体问题时也要提取。一句话有多问就拆开，保留原意与问题来源。

列出：原问题 → 需要的证据 → 现有依据及位置 → 缺口。区分描述不清、缺对照、机制未证实与实际错误。不从 confidence 推断身份、水平或意图。

## 2. 逐题回复

每问首句直接给结论或具体值，随后写设置、证据、解释和位置。感谢简短，标题忠于原问题；定义不清给定义，流程不清给案例，效果不清给对照。

合理批评就修正。有分歧时准确复述争议前提，用已有证据或针对性对照区分解释；不能区分就缩小主张，不以设计动机替代结果。补实验先交作者决定，不自动跑实验、改稿件或提交回复。

数字写绝对值、比较对象、分母、方向与必要条件。表格只放必要比较，保留影响判断的条件和不利结果。成本说明一次性与逐次开销、频率和单位。已完成的修改给位置；计划不能替代答案。

## 3. Revise loop

按原问题清单检查，不按当前回复的目录找问题：

1. 每个关切是否被明确回答？
2. 回复中的事实能否回到稿件、review、真实记录或已确认推导？
3. 证据是否真正区分争议解释，必要条件和范围是否保留？
4. 剩余疑问是什么？最小改法是什么？还缺哪项证据？

先修漏答、证据与逻辑，再压文字和调语气。只修改未通过项，改后重查同一清单；已有实验能回答时直接整理，不盲目重跑全部基线。新证据产生新问题时，补入清单。

问题覆盖完整、证据对应、逻辑通顺且篇幅与当轮政策合规后停止，交作者定稿。证据不足就列出缺口与所需决定，不凭模拟预测评分变化或录用。

## 4. 追问与 AC 总结

追问只处理新增关切，定位已有回应。AC 总结写关键问题、回应、证据与剩余分歧；引用已确认的评价，不推测未回复审稿人的态度，不请求提分或接收。
