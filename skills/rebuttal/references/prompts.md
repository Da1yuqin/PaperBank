# 给 Codex 的提示词

## 起草与逐题检查

```text
读取 rebuttal skill。目标会议与当轮规则：【】；论文：【】；完整 review：【】；已有结果及位置：【】；允许修改的文件：【】。先按审稿人拆出全部问题，编号 Q1.1、Q1.2；同一题有多问时用 Q1.2a、Q1.2b。每题用 > **Qx.x: 原问题** 开头，首句直接回答，再给证据、解释和位置。每位审稿人交付一份可复制 Markdown。随后运行 revise loop，按原问题检查漏答、证据与逻辑，只改未通过项。缺证据就列出缺口与最小检验，不自动跑实验、修改稿件或提交回复。不得编造结果、隐藏必要条件或预测提分。
```

## Revise loop

```text
运行 revise loop。输入为论文【】、原 review【】、回复【】、真实证据【】、当轮规则【】。

按 review 原顺序逐题检查：
1. 原问题是否有明确对应的 Q？
2. 首句是否直接回答，而非重复问题？
3. 证据是否支持结论、区分争议解释，且保留必要条件与范围？
4. 图表、引用和修改位置是否真实？

对未通过项输出：Q 编号｜原问题｜回复位置｜具体缺口｜最小改法｜还缺的证据。只修改获授权的回复文件，不自动跑实验或改稿。修改后重查同一清单；最终交付每位审稿人的独立 Markdown，把检查记录与证据缺口单独给作者。
```
