# CS 论文写作入口

先读一次[共享规则](../cs-writing-common/SKILL.md)，再只读当前任务涉及的章节；不默认加载全部模板。当前章规则与当前人工定版优先于历史写法。仅用于 CS 会议，Nature 系列使用独立体系。

| 任务 | 章节入口 |
| --- | --- |
| 摘要、引言与贡献 | [cs-abstract-introduction](../cs-abstract-introduction/SKILL.md) |
| 相关工作 | [cs-related-work](../cs-related-work/SKILL.md) |
| 方法、任务定义与 Overview | [cs-method](../cs-method/SKILL.md) |
| 实验、评价与诊断 | [cs-experiments](../cs-experiments/SKILL.md) |
| 图表、Caption 与排版 | [cs-visuals](../cs-visuals/SKILL.md) |
| 全文整合、标题、讨论、结论与附录 | [cs-integration](../cs-integration/SKILL.md) |

起草前先借鉴合适论文的组织逻辑，再根据自己的研究拟大纲。参考结构，不复制措辞、事实或贡献。

解压后保留全部八个同级目录。旧入口和下载地址保留，写作任务不需要同时加载绘图包。
