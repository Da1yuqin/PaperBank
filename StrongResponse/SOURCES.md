# 来源说明

StrongResponse 的规则、占位模板、模拟问题与模拟回复为 Da1yuqin 原创教学材料。网页、Markdown 和 rebuttal skill 由 `data/response.json` 中同一份内容生成，不摘录真实评审或私人审稿记录；当轮会议与平台规定优先。

问题拆解、证据匹配、首句直接回答与 revise loop 参考作者日常使用的 rebuttal、review-response、rebuttal-reviewer-profile、rebuttal-reviewer-simulator 与 auto-review-loop 的通用做法，重新表述为原创模板。未分发私人 skill 原件、真实审稿人画像或内部实验材料。

“了解你的审稿人”一章用高价值、关键、低价值分配回复精力。八种常见刻板印象直接描述话量、语气、评分、Confidence 与行为，不使用模拟审稿原话，不对应真实审稿人。“新手杀手：笑面虎审稿人”的特点与风险来自作者的经验判断。它们用于提醒回复投入，不报告参与率、提分率或录用率。

截至 2026-10-12 核对的 [ICLR 2026 Reviewer Guide](https://iclr.cc/Conferences/2026/ReviewerGuide) 要求审稿人参与讨论、考虑新信息并更新推荐，其示例评审明确给出澄清后愿意提高评分的条件。本章据此说明为何应寻找原文中的改评条件；画像与投入顺序是经验性建议，不是官方分类或已验证的行为预测。目标会议当轮规定优先。

配图为 AI 生成的教学插画，不对应真实审稿记录或录用结果。参考角色的权利归原权利人，本项目许可不授予第三方角色权利。

页面组织与表达受到 eternity4719 的[《高性价比人生指南》](https://eternity4719.github.io/HowToLiveBetter/)启发，正文与页面实现独立编写。通用教程编排 skill 保留原作者署名与许可。
