# 💪 StrongResponse

了解审稿人与偏好，逐题回复，按画像模拟复核，最后整理 AC letter。

[在线阅读](https://da1yuqin.github.io/StarPaper/StrongResponse/) · [Markdown 全文](book/response.md)

三个独立 skill：

- [审稿人画像与模拟](assets/rebuttal-reviewer-profile-skill.zip)：分析偏好，模拟审核，给出反馈。
- [Rebuttal](assets/rebuttal-skill.zip)：逐题起草、追问与依据反馈修改。
- [AC letter](assets/ac-letter-skill.zip)：整理正面评价、评分、真实改分与核心回应。

各自解压并保留完整文件夹，让 Codex 读取对应的 SKILL.md。画像与模拟审核，Rebuttal 修改，再用同一画像复核；全部回复完成后再写 AC letter。

论文写作请参考：[StarPaper](https://da1yuqin.github.io/StarPaper/)。
